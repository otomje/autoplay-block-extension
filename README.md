# Autoplay Block
Browser extension for blocking automatic video playback on all websites.

> [!NOTE]
> This is the first browser extension I've created. There may be bugs or incorrect code.

## Project Information
1. This project uses the `GULP` task runner.
2. Styles for the project are written in the `SASS` preprocessor, using the `SCSS` dialect.
3. Classes in `HTML` follow the `BEM` methodology.

## Installation
1. Go to [Releases](https://github.com/otomje/autoplay-block-extension/releases), choose the latest version, and download the archive named `autoplay-block-extension-vX.X.X.zip`.
2. Create a folder with any name, in any location on your computer.
3. Extract the archive into the folder you created.
4. Open your browser (I'll use `Chrome` as an example), click the extensions icon, and then select **Manage extensions**.
5. Enable **Developer mode**, then click **Load unpacked**.
6. Then select the folder you created, and that's it. You can now use the extension like any regular one.
